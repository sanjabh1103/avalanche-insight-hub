# Zenodo / OSF Publication Readiness

## Claim Boundary

This is a readiness checklist only. No Zenodo, OSF, DOI, or public scientific release is claimed until the checklist is complete and approved.

## Minimum Package

| Package item | Required status |
|---|---|
| Dataset manifest | Real source rows only; synthetic demo rows excluded. |
| License review | Explicit license per data source. |
| Model card | Current RF baseline separated from gated SAR/MTS-LSTM candidates. |
| Evaluation report | PSS, Brier, calibration, slice performance, and scientist-review boundary. |
| Reproducibility commands | Exact scripts, versions, and artifact paths. |
| Ethics/safety note | Warning-authority and decision-support boundary. |
| Review sign-off | Scientist and operator approval before publication. |
