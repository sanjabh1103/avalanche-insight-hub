## Speaker Notes

- Do say:
  - “The live MVP uses an explainable baseline today.”
  - “The current active full-grid artifact uses heuristic explanation fallback, with TreeSHAP kept as an implemented hardening path.”
  - “Modal.com already powers heavier off-path ML and remote-sensing workflows.”
  - “The MTS-LSTM and SAR paths are real, but still gated.”
  - “Say `Modal.com`, not `Model.com`.”

- Do not say:
  - “Modal GPU models are already driving the public forecast.”
  - “Production MTS-LSTM is active.”
  - “Operational SAR has already been promoted.”

- Keep the close clean:
  - “Modal.com helps us move heavy training and remote-sensing work off the user path today, and it gives us a credible route to improve prediction quality later if the candidate paths earn promotion.”
