# European Shadow Evidence Pack

Status date: 2026-05-21

This folder is the European shadow-validation evidence pack for Avalanche Insight Hub. It is not a production prediction lane and must not be used as proof of Himalayan accuracy.

## Current Representation

The current branch is `feature/european-data-shadow-pipeline`. Treat this branch and folder as a validation/research surface until the shadow evidence is merged with explicit claim boundaries or superseded by partner-confirmed Himalayan evidence.

European evidence is useful for:

- external benchmark lineage: AvalCD, SnowSlide, SLF/SPOT6-style sources
- SAR qualification and failure analysis
- manual-review workflow design
- production-promotion blockers
- transfer-learning caution for Himalayan deployment

European evidence is not useful for:

- claiming Himalayan accuracy
- activating public SAR scoring
- claiming SnowSlide research-grade acceptance before manual review closes
- bypassing scientist or partner validation

## Scientist Review Use

Scientists should use this pack to review:

- whether SnowSlide errors are label/source issues, valid model errors, terrain/SAR ambiguity, or unresolved source context
- which SAR failure modes matter for Himalayan terrain
- which benchmark gates are sufficient before any public claim upgrade
- whether European evidence suggests useful features or workflows for Himalayan partner-data pilots

Scientists should not use this pack to certify Himalayan operational accuracy.

## Himalaya Transfer Boundary

European data can test methods, stress SAR workflows, and expose failure modes. It cannot replace Himalayan field reports, partner-verified historical events, bulletin archives, station/weather records, or HIM-STRAT-style snowpack evidence.

Promotion from European shadow evidence to Himalayan model claims requires:

1. partner-confirmed Himalayan source rows
2. scientist review and action closure
3. paired model-vs-scientist verification
4. benchmark evidence against the current RF baseline
5. explicit release-gate approval

## Never Claim

- European data proves Himalayan accuracy.
- Modal GPU evidence means production SAR is active.
- AvalCD pass means SnowSlide pass.
- SnowSlide v8 is research-grade accepted.
- SAR, MTS-LSTM, or public scoring can promote from this folder alone.
