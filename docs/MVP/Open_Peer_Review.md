# Open Peer Review Register

Status: prepared register, not publicly opened.

This file tracks future public-review surfaces for scientist validation artifacts. It does not claim that GitHub Discussions, OSF, Zenodo, or any other public surface has been opened.

## Governance Boundary

- Public review requires repository or platform admin approval.
- Partner-provided or confidential data must not be posted publicly unless license terms allow it.
- Synthetic demo cases must remain labelled as demo-only.
- Public-source candidate cases remain unconfirmed until scientist review.
