## Unique And Specific Value In This File

- It keeps Deck 1 and Deck 2 in one place for slide-build sequencing.
- It separates the two narrative jobs clearly: Deck 1 proves the current MVP honestly; Deck 2 converts the gap into a scientist-led validation path.
- It gives each slide a short build instruction, proof bucket, and source anchor without carrying the full detail of the canonical outlines.
- It is useful as a quick deck-builder brief when generating a fresh slide deck, especially if the full source pack is too large for one prompt.

## Current Proof Rules

- Use `Hosted production` only for what the hosted public or admin route proves.
- Use `Repo/admin verified` for implemented source, artifact, test, or authenticated operator evidence.
- Use `Artifact/doc proof only` for research, protocols, ledgers, benchmark packs, and planning artifacts.
- The May 8 public proof is a same-day full-grid cell publication for Colorado Rockies; use `current published forecast` language with the scientist-validation caveat.
- Use stale/fallback language only when same-day artifact proof is absent.
- MTS-LSTM, SAR, WhiteboxTools runout, and full autonomy stay candidate, gated, or proposed unless the evidence map says otherwise.
