# VoltAgent Noir Control Room

This portal should feel like a high-trust operations console: dark, precise, and cinematic, with emerald status accents, crisp typography, and a dense but orderly layout.

## Visual Direction

- Base the interface on a deep charcoal canvas with layered glass surfaces.
- Use emerald as the primary active/status color.
- Keep highlights restrained and functional, not decorative.
- Favor tight information hierarchy, compact spacing, and strong contrast.

## Layout Rules

- Treat the map as the primary canvas.
- Present control surfaces as floating panels or rails instead of flat sections.
- Keep the sidebar collapsible and visually lighter than the map.
- Use compact metric chips and small caps labels for telemetry.

## Component Rules

- Cards should use subtle borders, soft blur, and minimal shadows.
- Buttons should feel technical and deliberate, with clear hover states.
- Status badges should be monospaced and high-contrast.
- Panels should read like instrumentation, not consumer app widgets.

## Typography

- Use a clean sans-serif for body text and a mono face for telemetry.
- Headings should be tight and direct.
- Secondary labels should be uppercase with tracking.

## Motion

- Use short, smooth transitions.
- Sidebar and modal motion should feel controlled, not playful.
- Do not over-animate data-heavy surfaces.

## Do

- Keep the dashboard legible at a glance.
- Preserve accessibility and keyboard behavior.
- Emphasize live status, freshness, and model state.

## Don't

- Don't introduce bright pastel UI.
- Don't use soft, generic SaaS styling.
- Don't make the map secondary to the control panels.
